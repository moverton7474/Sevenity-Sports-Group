Personal Development Plans

What a Sevenity development plan looks like.

Every athlete gets a written plan with clear phases and objectives — so each session has a purpose and progress can be measured. Below is a real example: the in-season plan built for Ramone Seals.

Athlete
Ramone Seals
Example Plan

Development plan — four phases.

  1. I

    Offensive Command

    Objective: Develop offensive control through pace, advantage creation, and decision-making.

  2. II

    Shot Creation & Efficiency

    Objective: Improve shot creation, scoring efficiency, and game-speed execution.

  3. III

    Decision-Making & Read Progressions

    Objective: Improve offensive reads, defensive recognition, and real-time decision-making.

  4. IV

    Game Performance & Situational Execution

    Objective: Transfer skills into competitive game situations with disciplined execution.

How It Runs

In-season performance development.

01

Film Breakdown

Every session begins with film review to identify strengths, weaknesses, and priorities.

02

On-Court Application

Workouts directly apply film findings through individualized skill development.

03

Offensive Efficiency

Emphasize shot selection, offensive reads, paint touches, and decision-making.

04

Quarterly Evaluation

Complete a performance review and establish priorities for the next Tune-Up.
